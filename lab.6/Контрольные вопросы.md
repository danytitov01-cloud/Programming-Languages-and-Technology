Контрольные вопросы

• 10. Что такое DOM? Document Object Model (DOM) — это объектная модель документа, представляющая структуру HTML-страницы в виде дерева объектов, доступного для изменения и управления с помощью JavaScript.

• 11. Чем querySelector() отличается от querySelectorAll()? querySelector() находит и возвращает только первый элемент, соответствующий указанному CSS-селектору. querySelectorAll() находит все подходящие элементы и возвращает их в виде статической коллекции NodeList.

• 12. Как создать новый HTML-элемент из JavaScript? Новый элемент создается в оперативной памяти с помощью метода document.createElement(tagName), где tagName — имя тега (например, 'li', 'div').

• 13. Как добавить созданный элемент на страницу? Для этого созданный узел вставляется в дерево DOM как дочерний элемент к существующему родителю с помощью методов appendChild(element) или append(element).

• 14. Как удалить DOM-элемент? Современный и прямой способ удаления элемента из структуры документа — вызов метода element.remove() непосредственно на самом удаляемом объекте.

• 15. Для чего применяется addEventListener()? Этот метод используется для регистрации обработчика события на целевом объекте (кнопке, поле ввода, документе). Он позволяет выполнять функцию, когда пользователь совершает определенное действие (клик, ввод текста).

• 16. Что такое объект event? Это объект события, который автоматически передается браузером в функцию-обработчик. Он содержит всю сопутствующую информацию о произошедшем событии (тип события, координаты мыши, нажатая клавиша, элемент-источник).

• 17. Как определить нажатую клавишу? Внутри обработчика событий клавиатуры (keydown, keyup) нажатая клавиша определяется путем обращения к свойствам event.key (возвращает символьное значение, например, 'Enter') или event.code (физический код клавиши).

• 18. Чем click отличается от keydown? click — это событие мыши (или тачскрина), происходящее при нажатии и отпускании основной кнопки мыши на элементе. keydown — это событие клавиатуры, происходящее в момент непосредственного нажатия любой клавиши на физической клавиатуре.

• 19. Что такое всплытие событий? Всплытие (bubbling) — это фаза жизненного цикла события, при которой возникшее на самом глубоком элементе событие последовательно передается вверх по цепочке предков к его родителям вплоть до объекта window.

• 20. Для чего используется classList? Свойство classList возвращает динамическую коллекцию CSS-классов элемента и предоставляет удобные методы для управления ими из JavaScript: .add(), .remove(), .toggle() (переключить) и .contains() (проверить наличие).

• 21. Чем textContent отличается от innerHTML? textContent считывает и вставляет исключительно безопасный чистый текст, экранируя любые символы разметки. innerHTML работает с содержимым как с полноценным HTML-кодом, интерпретируя и рендеря теги, что может быть уязвимо к XSS-атакам.

• 22. Как изменить атрибут элемента? Атрибут можно изменить напрямую через его свойство (например, element.id = 'new-id') или с помощью универсального встроенного DOM-метода element.setAttribute(name, value).

• 23. Почему нежелательно назначать множество одинаковых обработчиков? Это приводит к избыточному потреблению оперативной памяти, замедлению работы интерфейса и утечкам памяти при удалении элементов. Вместо этого профессионалы используют паттерн делегирования событий (один общий слушатель на родительский контейнер).

• 24. Как можно проверить корректность работы динамического интерфейса? С помощью ручного тестирования по тест-кейсам, мониторинга вкладки Console на наличие ошибок в DevTools браузера, инспектирования динамического изменения структуры тегов во вкладке Elements и написания автоматизированных UI-тестов.
