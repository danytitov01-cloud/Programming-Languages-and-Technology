## 📌 Номер и условия вариантов
* **Задание №3** (Базовый уровень): Настройки темы (светлая/темная) и размера текста с сохранением выбранных настроек в `localStorage`[cite: 2].
* **Задание №9** (Средний уровень): Учет расходов (категория, сумма, дата) с сохранением операций в виде массива объектов через `JSON.stringify()` и вычислением общего расхода[cite: 2].
* **Задание №18** (Повышенный уровень): Система бронирования учебных комнат (дата, время, помещение) с сохранением записей и предупреждением пользователя о конфликтах при попытке забронировать занятый слот[cite: 2, 3].

---

## 🎯 Цель работы
Освоить сериализацию и десериализацию объектов JavaScript в формат JSON, хранение данных в `localStorage` и `sessionStorage`, восстановление интерфейса после обновления страницы, а также удаление сохраненных записей[cite: 1]. Научиться работать с методами `setItem()`, `getItem()`, обрабатывать отсутствие данных и поврежденный JSON с помощью конструкций `try...catch` без аварийного завершения приложения[cite: 1, 2].

---

## ⚙️ Входные и выходные данные

### Задание №3 (Базовый уровень):
* **Входные данные:** Событие выбора темы из выпадающего списка/карточек, событие изменения ползунка размера шрифта.
* **Выходные данные:** Изменение CSS-классов и стилей документа, сохранение конфигурации в `localStorage`.

### Задание №9 (Средний уровень):
* **Входные данные:** Выбранная категория расхода, числовое значение суммы, дата транзакции, действия добавления/удаления.
* **Выходные данные:** Массив объектов расходов, сериализованный в JSON-строку и записанный в `localStorage`[cite: 1, 2]. Динамический пересчет и вывод общей суммы расходов[cite: 2].

### Задание №18 (Повышенный уровень):
* **Входные данные:** Выбранная учебная аудитория, дата, временной слот, введенные данные пользователя.
* **Выходные данные:** Проверка массива существующих броней на наличие коллизий (конфликтов)[cite: 3]. Запись новой брони в `localStorage` или вывод предупреждающего модального окна[cite: 2, 3].

## 🛠️ Алгоритм решения
1. **Разметка интерфейса (HTML5):** Создание адаптивных интерфейсов для каждого из выбранных вариантов с использованием семантических тегов и элементов управления.
2. **Оформление и интерактивность (CSS3):** Разработка современного дизайна с применением CSS-переменных, адаптивных сеток (Grid/Flexbox) и плавных анимаций.
3. **Логика JavaScript и Web Storage:**
   * **Вариант №3:** Чтение персистентных настроек при инициализации страницы и мгновенное применение стилей.
   * **Вариант №9:** Безопасная десериализация данных через `JSON.parse()` в блоке `try...catch`, добавление транзакций в массив объектов и сохранение через `JSON.stringify()`[cite: 1, 2].
   * **Вариант №18:** Использование метода `Array.prototype.some()` для детекции пересечений бронирования по аудитории, дате и времени[cite: 3].

## 🎯 Вывод
В ходе выполнения лабораторной работы были успешно освоены механизмы сериализации и десериализации данных в формат JSON с помощью методов `JSON.stringify()` и `JSON.parse()`[cite: 1, 2]. На практике изучены различия между постоянным (`localStorage`) и сессионным (`sessionStorage`) хранилищами, методы управления записями (`setItem`, `getItem`, `removeItem`, `clear`)[cite: 1, 2]. Реализовано восстановление состояния интерфейса после перезагрузки страниц, а также защита от поврежденных данных с помощью блоков `try...catch`[cite: 1, 2]
