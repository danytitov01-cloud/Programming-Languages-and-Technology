# Лабораторная работа №9
## Асинхронные запросы (Fetch API, AJAX)

### 1. Цель работы

Изучить принципы выполнения асинхронных HTTP-запросов с использованием Fetch API, научиться получать данные из публичного REST API, обрабатывать JSON и динамически отображать информацию на веб-странице.

### 2. Используемые технологии

- HTML — создание структуры веб-страниц.
- CSS — оформление интерфейса.
- JavaScript — обработка данных и взаимодействие с пользователем.
- Fetch API — выполнение HTTP-запросов.
- async/await — работа с асинхронными операциями.
- Promise.all() — параллельное выполнение нескольких запросов.
- JSONPlaceholder — публичный API для получения демонстрационных данных.

Адрес API: https://jsonplaceholder.typicode.com/

### 3. Выполнение заданий

**Задание №1. Базовый уровень**

Разработано приложение для получения первых десяти публикаций с сервера. Для каждой публикации отображаются её идентификатор и заголовок. Добавлена кнопка загрузки, сообщение о состоянии запроса и обработка ошибок.

**Задание №8. Средний уровень**

Разработано приложение для отображения публикаций с возможностью поиска по заголовку. После загрузки данные сохраняются в массиве. При вводе текста выполняется фильтрация на стороне клиента без повторного запроса к серверу. Результаты автоматически обновляются на странице.

**Задание №18. Повышенный уровень**

Разработано приложение для параллельной загрузки пользователей и публикаций с помощью Promise.all(). После получения данных программа подсчитывает количество публикаций, принадлежащих каждому пользователю, и отображает результат в виде карточек. Также выводится общее количество пользователей и публикаций.

### 4. Алгоритм работы

1. Пользователь нажимает кнопку загрузки.
2. JavaScript отправляет запросы к REST API.
3. Программа проверяет успешность HTTP-ответа.
4. Ответ преобразуется в JSON.
5. Полученные данные обрабатываются.
6. Создаются HTML-элементы и отображаются результаты.
7. При возникновении ошибки выводится соответствующее сообщение.

### 5. Таблица тестирования

| № | Проверка | Ожидаемый результат |
|---|---|---|
| 1 | Загрузка публикаций | Отображаются 10 публикаций с ID и заголовками |
| 2 | Поиск по заголовку | Отображаются совпадающие публикации |
| 3 | Поиск без совпадений | Отображается нулевое количество результатов |
| 4 | Загрузка статистики | Отображаются пользователи и число их публикаций |
| 5 | Отключение интернета | Появляется сообщение об ошибке |
| 6 | Повторная загрузка | Запрос выполняется повторно |

Фактические результаты необходимо подтвердить запуском приложений в браузере.

### 6. Вывод

В ходе лабораторной работы подготовлены три веб-приложения разного уровня сложности. Были изучены асинхронные запросы Fetch API, получение и обработка JSON-данных, динамическое изменение DOM, фильтрация информации и параллельная загрузка данных с использованием Promise.all(). Также предусмотрена обработка ошибок и повторная загрузка данных.

Полученные навыки позволяют создавать веб-приложения, которые получают информацию с сервера и отображают её без полной перезагрузки страницы.
