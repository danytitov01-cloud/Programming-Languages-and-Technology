8. Контрольные вопросы
16. Для чего используется JavaScript в браузере?
JavaScript используется для добавления интерактивности веб-страницам. С его помощью можно реагировать на действия пользователя, изменять содержимое страницы, проверять введённые данные, выполнять вычисления и работать с DOM.

17. Чем let отличается от const?
let используется для переменной, значение которой можно изменить:

let age = 18;
age = 20;

const используется для переменной, которой нельзя присвоить новое значение:

const name = "Иван";

18. Что такое условный оператор?
Условный оператор позволяет выполнять разные действия в зависимости от условия.

Например:

if (age >= 18) {
    console.log("Совершеннолетний");
} else {
    console.log("Несовершеннолетний");
}

19. Какие циклы есть в JavaScript?
Основные циклы:

for;

while;

do...while;

for...of;

for...in.

Например:

for (let i = 0; i < 5; i++) {
    console.log(i);
}

20. Что такое функция и параметры функции?
Функция — это блок кода, который можно многократно выполнять.

Параметры — данные, которые функция получает при вызове.

function sum(a, b) {
    return a + b;
}

console.log(sum(5, 3));

Здесь a и b являются параметрами функции.

21. Что такое DOM?
DOM (Document Object Model) — объектная модель HTML-документа. Она представляет HTML-страницу в виде дерева объектов, с которыми может работать JavaScript.

Например:

document.getElementById("result");

позволяет получить элемент страницы с указанным идентификатором.

22. Как получить HTML-элемент в JavaScript?
Существует несколько способов. Например:

document.getElementById("result");

или:

document.querySelector(".button");

Также можно получить несколько элементов:

document.querySelectorAll("li");

23. Чем textContent отличается от value?
value обычно используется для получения или изменения значения элементов формы:

input.value

textContent используется для получения или изменения текстового содержимого элемента:

element.textContent = "Привет";

Например, в нашей работе:

const age = Number(ageInput.value);

получает введённый пользователем возраст, а:

result.textContent = "Вы совершеннолетний";

выводит результат на страницу.

24. Что такое событие?
Событие — это действие, которое произошло на странице или в браузере.

Например:

нажатие кнопки;

ввод текста;

изменение значения;

нажатие клавиши;

отправка формы.

Для обработки событий используется:

addEventListener()

25. Для чего используется addEventListener()?
Метод addEventListener() позволяет назначить обработчик события элементу.

Например:

button.addEventListener("click", function () {
    alert("Кнопка нажата");
});

При нажатии на кнопку выполняется указанная функция.

26. Как добавить или удалить CSS-класс через DOM?
Для работы с классами используется свойство classList.

Добавить класс:

element.classList.add("active");

Удалить:

element.classList.remove("active");

Переключить:

element.classList.toggle("active");

В нашем списке задач использовалось:

span.classList.toggle("completed", checkbox.checked);

27. Как создать HTML-элемент с помощью DOM?
Используется метод:

document.createElement()

Например:

const li = document.createElement("li");

После создания элемент можно добавить на страницу:

taskList.appendChild(li);

28. Почему браузер может выполнять JavaScript?
Современные браузеры имеют встроенные JavaScript-движки. Они считывают JavaScript-код, интерпретируют или компилируют его и выполняют непосредственно в браузере.

Например, в Google Chrome используется движок V8.

29. Как разделение HTML и JavaScript улучшает структуру проекта?
Разделение позволяет сделать проект более организованным:

HTML отвечает за структуру страницы;

CSS — за внешний вид;

JavaScript — за логику и интерактивность.

Например:

project/
│
├── index.html
├── style.css
└── script.js

Такой подход облегчает поиск ошибок, изменение кода и дальнейшее развитие проекта.

30. Как разделение HTML и JavaScript улучшает структуру проекта?
Разделение HTML и JavaScript позволяет не смешивать структуру документа с программной логикой. Благодаря этому код становится понятнее, его проще тестировать и изменять. Также один JavaScript-файл можно подключать к нескольким HTML-страницам.
